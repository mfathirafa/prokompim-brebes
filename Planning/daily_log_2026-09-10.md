## Error yang Pernah Terjadi

### Error 1: TypeScript - createBrowserClient not found
```
src/lib/supabase/client.ts:1:10 - error TS2305: Module '"@supabase/supabase-js"' has no exported member 'createBrowserClient'.
```

**Solusi:**
Ganti import dari:
```typescript
import { createBrowserClient } from "@supabase/supabase-js"
```
Menjadi:
```typescript
import { createClient as createSupabaseClient } from "@supabase/supabase-js"
```
