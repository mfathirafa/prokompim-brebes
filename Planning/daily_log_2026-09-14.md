## Kendala & Solusi Hari Ini

### 1. Error `42703: column "is_approved" does not exist`
* **Penyebab:** Tabel `komentar` versi lama sudah ada di database tanpa kolom `is_approved`. Perintah `CREATE TABLE IF NOT EXISTS` melewati pembuatan tabel baru sehingga saat index dibuat terjadi kegagalan.
* **Solusi:** Menjalankan skrip `DROP TABLE ... CASCADE` untuk membersihkan tabel lama sebelum menjalankan migrasi baru.

### 2. Error `42710: trigger "profiles_updated_at" already exists`
* **Penyebab:** PostgreSQL menolak membuat trigger dan policy dengan nama yang sama jika skrip dijalankan ulang.
* **Solusi:** Menambahkan klausa `DROP TRIGGER IF EXISTS` dan `DROP POLICY IF EXISTS` di seluruh tabel agar skrip migrasi bersifat idempotent.

### 3. Error PowerShell Redirection Operator saat Generate Types
* **Penyebab:** Perintah terpotong menjadi multi-line di terminal PowerShell dan terjadi prompt konfirmasi npx.
* **Solusi:** Menjalankan perintah satu baris dengan flag `-y` dan `Out-File -Encoding utf8`, atau menyalin langsung types dari Supabase Dashboard menu Project Settings → API.
