## Kendala & Solusi Hari Ini

### 1. Error 500 `ERR_INVALID_URL` pada Image Optimization Beranda
* **Penyebab:** Kolom `cover_url` pada 6 baris tabel `liputan` Supabase terisi string dengan format spasi dan enter (`placehold.  \r\n  co/...`).
* **Solusi:** Menyiapkan sanitasi string `.replace(/\s+/g, "")` di komponen kartu tampilan serta query `REGEXP_REPLACE` di Supabase SQL Editor.

### 2. Error TS2339: Property 'auth' does not exist on type 'Promise<...>'
* **Penyebab:** Pada `src/app/(auth)/login/page.tsx`, fungsi `createClient` terimpor dari `@/lib/supabase/server` (yang bersifat *asynchronous* mengembalikan Promise) bukannya dari browser client `@/lib/supabase/client`.
* **Solusi:** Mengubah target import pada baris 6 `src/app/(auth)/login/page.tsx` menjadi `@/lib/supabase/client`.
