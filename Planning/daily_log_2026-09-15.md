## Kendala & Solusi Hari Ini

### 1. Ikon Media Sosial Lucide Tidak Ditemukan
* **Penyebab:** Versi paket `lucide-react` terbaru tidak lagi menyertakan brand icons seperti Facebook, Instagram, Twitter, dan YouTube karena keterbatasan scope library ikon generik.
* **Solusi:** Membuat SVG inline path khusus untuk masing-masing ikon sosial media di komponen `footer.tsx` dengan styling Tailwind yang konsisten.

### 2. Inkonsistensi Opacity Modifier Tailwind pada CSS Variables
* **Penyebab:** Definisi variabel CSS lama tanpa wrapper `hsl()` menyebabkan beberapa class seperti `bg-brand-gold/15` atau `bg-primary/90` menghasilkan warna fallback tak terduga di browser.
* **Solusi:** Menyelaraskan seluruh root token warna di `globals.css` ke format `hsl(h s% l%)` sehingga Tailwind CSS v4 / v3.4 dapat memproses channel transparansi secara sempurna.
